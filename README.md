# Venous thromboembolism (VTE) risk assessment - Publication code

This repository contains the analytical code used by NHS England to produce the quarterly [Venous thromboembolism (VTE) risk assessment Official Statistics](https://www.england.nhs.uk/statistics/statistical-work-areas/vte/).

## Purpose

The scripts in this repository are used to process and publish aggregate VTE risk assessment data submitted by providers quarterly to NHS England. The repository is published to support transparency.

## Data sources 

The published statistics are derived from aggregate VTE risk assessment data submitted by providers and used alongside reference data from the Organisation Data Service (ODS).

Data used is accessed via secure NHS England systems and is not part of this repository.

## How to use this repository

This repository is primarily intended for:

-   Transparency for users of the published statistics.

-   Internal reuse or adaptation with appropriate data access.

The code cannot be run without access to secure NHS England systems.
